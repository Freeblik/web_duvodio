Duvodio landing page update

Files:
- index.html: updated landing page, styling and interactive demo controls
- app.js: CZ/EN toggle and illustrative lead-change calculator

How to use:
1. Upload index.html and app.js to the same folder in your GitHub Pages repository.
2. Keep the current folder/path structure, or rename index.html to the site's existing entry file if needed.
3. The live demo URL is currently http://94.237.27.165:9005/ and is configured in the CTA links in index.html.
4. Before public launch, put the demo behind HTTPS and update the CTA URLs.

Important:
The slider uses a deliberately illustrative formula (50% more leads -> 8% change in contracts). It is not connected to the Duvodio backend or its forecasting model.
